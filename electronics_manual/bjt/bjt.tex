\textbf{Transistor Biasing}

You have just seen that a single npn transistor doesn't work for AC signals; current can only flow one way through the base-emitter junction, cutting off the bottom half of the input signal.  A common technique for getting around this problem is to add a DC \textit{bias} voltage to the input signal, so that $\Delta V_\text{BE}$ remains positive at all times.%

\textbf{A Push-Pull  Amplifier}

\medskip
Adding a DC bias to an AC signal to ensure that it falls in a specific range is a trick that is used in a wide variety of circuits.  It can allow polarized components like a transistors to be used for AC signals, and can also let AC signals be handled in circuits using only a single positive power supply as opposed to both a $V_\text{CC}$ and a $V_\text{EE}$.  But it comes with disadvantages as well: the amplifier you just built in the previous part is extremely inefficient, with significantly more power dissipated in $R_\text{discharge}$ and the transistor than in $R_\text{load}$.

\item An alternative to DC biasing is to employ both npn and pnp transistors for the positive and negative phases of an AC input signal, respectively.  In the circuit shown below, the 2N3904 npn transistor handles the input signal's positive phase, and the complimentary 2N3906 pnp transistor handles the negative phase, an arrangement called a \textit{push-pull amplifier}.%
\footnote{In fact, there is a whole nomenclature system describing different power amplifier configuations.  The single-transistor circuit you built in part~\ref{part_biased_output_and_input_correct} is a ``class A'' amplifier, and the push-pull amplifier in part~\ref{part_push_pull_amp} is a ``class B'' amplifier.  Variations on the latter that use small offsets to minimize crossover distortion  are called ``class AB'' amplifiers, and there are even class C, D, E, F, G, and H amplifiers as well---the engineers having clearly stayed up all night thinking of what to name all of these.}

The primary issue with the simple push-pull amplifier above is the hiccup in the output that occurs as the input crosses zero volts.  There are several strategies for minimizing this \textit{crossover distortion}, ranging from using resistors or additional diodes to add $\pm \sim$0.7-volt offsets to the transistor inputs, to using op-amp feedback similar to what you did in
