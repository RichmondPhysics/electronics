A flip-flop is a device that holds a single bit of memory: either a logical ``0'' or ``1'', represented by an output voltage of either 0 V or 5 V.  Unlike a NAND or NOR gate that changes its output based on the instantaneous values of its inputs, a flip-flop's output remains constant (that is, it ``remembers'' a value of 0 or 1) unless it is given a specific input signal to change its value.

\textbf{Synchronous Operation}

The SET and RESET inputs are one method of controlling the output of the flip-flop, called ``asynchronous'' operation.  But the output can also be controlled in a ``synchronous'' mode, in which changes in the output must be triggered by a separate clock signal.%
\footnote{Although the term \textit{flip-flop} is often used to include both synchronous and asynchronous operation, some authors make a point of describing any asynchronous device as a \textit{latch}, as in the \textit{SR latch} you have just used.  Adding to the confusion, the term \textit{flip-flop} includes an alphabet soup of different types (D-type, T-type, or JK-type, each following a different set of rules) as well as variations on whether changes in output are triggered by a rising clock, a falling clock, or both. All of this is far more than we need to tackle in this course, but consider yourself forewarned that the next ``flip-flop'' you encounter in the wild may behave differently than the CD4013 chip you've seen here.}
